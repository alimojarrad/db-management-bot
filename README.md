# Agentic Database Management Bot

Managing databases often requires writing SQL, understanding schemas, and knowing exactly what data to modify. For non-technical users, even simple database operations can become difficult and error-prone.

This project explores a simpler approach: **interacting with a database through natural language**.

Users can describe what they want in Telegram, while an AI agent handles the database interaction behind the scenes.

The goal is to make database management more **accessible, intuitive, and controlled** without requiring users to write SQL themselves.
